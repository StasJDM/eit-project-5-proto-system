# Проект 5 — Прототип системы мониторинга ЭИТ

## Назначение

Программный прототип монитора пациента на основе электроимпедансной томографии (ЭИТ).
Источник требований: `../eit_project_4_monitoring/docs/tech_task.md` (ТЗ).

**Цель прототипа**: продемонстрировать интерфейс и экранные формы. Реальных вычислений нет — используются мок-данные, симулирующие нормальное дыхание (эупноэ, 15 вд/мин).

---

## Запуск

```bash
cd project_5_proto_system
pip install -r requirements.txt
python main.py
```

**Зависимости**: PySide6, numpy.

## Многоязычность (п.7 ТЗ)

Поддерживаются 4 языка: **русский, английский, китайский, вьетнамский**.

**Как это работает:**
1. `app/i18n.py` содержит словарь `STRINGS` — все строки на 4 языках
2. Вызов `t("key")` возвращает строку для текущего языка
3. `i18n.language_changed` — сигнал Qt; все виджеты подключаются к нему и вызывают `retranslate()`
4. Смена языка производится через экран «Системная информация» → кнопка «Изменить язык»

**Как добавить новую строку:**
1. Добавить ключ в `STRINGS` в `app/i18n.py` (все 4 языка обязательны)
2. Добавить строку в `translations.md`
3. В виджете использовать `t("key")` и добавить `retranslate()` метод

## Как добавить новый экран

1. Создать `app/screens/<name>_screen.py`, унаследоваться от `BaseScreen` (или написать QWidget с нуля).
2. Зарегистрировать в `app/main_window.py`:
   ```python
   self._register("key", MyScreen())
   ```
3. Убедиться, что ключ совпадает с NAV_ITEMS в `app/widgets/nav_panel.py`.
