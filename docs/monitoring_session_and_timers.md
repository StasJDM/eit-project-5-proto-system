# Сессия мониторинга и счётчики времени

## Единое управление

Все кнопки Start/Stop вызывают `MonitoringController`. Контроллер согласованно
управляет состоянием исследования, источником данных, фоновой обработкой,
записью кадров и счётчиком электродной системы. Самостоятельный запуск источника
при открытии приложения отсутствует.

Кнопка Start доступна сразу после открытия главного экрана. Если пациент уже
выбран, новое исследование автоматически привязывается к нему. Если выбранного
пациента нет, приложение создаёт и затем повторно использует одну служебную
карточку `AUTO-PATIENT`, создаёт и подготавливает исследование и только после
этого запускает контроллер. После Stop следующий Start автоматически создаёт
новое исследование; дубликаты служебной карточки не создаются.

При старте сначала проверяется качество контакта, затем создаётся сессия и
открывается запись, после чего запускаются источник и обработка. Ошибка запуска
завершает уже созданную сессию со статусом `failed`, закрывает запись и источник.
Повторный Start для работающей сессии отклоняется. При штатном закрытии
приложения активное исследование завершается с причиной `application_closed`.

## Семантика времени

- **Длительность ЭИТ** — сумма UTC-интервалов, в которых исследование имеет
  состояние `running`. Она начинается с `00:00:00`, не растёт на паузе и
  фиксируется при остановке. Исходные отметки и накопленная длительность пауз
  хранятся в записи сессии.
- **Использование электродной системы** — накопленное время, когда источник ЭИТ
  работал в составе активной сессии. Оно не растёт до Start, во время Pause и
  после Stop. Значение сохраняется в настройках при каждой паузе, остановке и
  закрытии приложения, поэтому восстанавливается после перезапуска.

Интерфейсный таймер только обновляет отображение раз в секунду. Источником
значений являются сохранённые UTC-интервалы, а не количество срабатываний
таймера, поэтому задержка UI не изменяет измеренную длительность.
