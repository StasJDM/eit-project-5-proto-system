# Формат экспорта ЭИТ

Версия контракта: `eit-export-1.0.0`.

## Общие правила

- Каждый запуск создаёт новый каталог `eit_export_<UTC>`; сначала он целиком
  формируется во временном соседнем каталоге, затем публикуется атомарным
  переименованием.
- `manifest.json` содержит версию схемы, UTC-время создания, формат, точный
  список исследований и категорий, размер и SHA-256 каждого файла данных.
- Даты и время записываются в ISO 8601 UTC (`Z`), UUID — строками.
- `null` в JSON и пустая ячейка в CSV/XLSX означают недоступное значение.
- Числа хранятся с точкой как десятичным разделителем и без единиц в значении;
  единицы следуют из имени поля (`*_bpm`, `*_au`, `*_seconds`).

## JSON

`data.json` имеет корневые поля `schema_version`, `created_at_utc`,
`categories`, `studies`. Каждый элемент `studies` всегда содержит `study_id` и
только запрошенные категории: `metadata`, `metrics`, `trends`, `events`,
`raw_data`. Вложенные доменные объекты сохраняют свои `model_type` и
`format_version`.

## CSV

- Кодировка: UTF-8 с BOM (`utf-8-sig`) для корректного открытия в табличных
  приложениях.
- Разделитель: точка с запятой (`;`).
- Окончание строки: CRLF.
- Каждая выбранная категория формирует отдельный файл; вложенные поля
  разворачиваются через точку, массивы записываются компактным JSON.

## Excel

Книга OOXML `.xlsx` содержит отдельные листы выбранных категорий. Первая строка
— заголовки. Числа записываются как числовые ячейки, даты — как ISO 8601. При
превышении лимита Excel в 1 048 576 строк категория разбивается на листы с
суффиксом `_N`.
