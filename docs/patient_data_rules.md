# Правила данных пациента (TASK-7–TASK-10)

## Обязательные поля карточки

- фамилия и имя: 1–64 символа, без цифр;
- дата рождения: не позднее текущей даты;
- пол: `male` или `female`;
- масса: 0,5–500 кг;
- рост: 20–250 см;
- охват грудной клетки: 20–250 см;
- ID пациента: 3–32 символа, латинские буквы, цифры, `.`, `_`, `-`;
- номер истории болезни: 1–64 буквы/цифры либо `.`, `_`, `/`, `-`.

ID пациента и номер истории болезни уникальны. Сгенерированный ID имеет формат
`P-XXXXXXXX`. Ручной ID нормализуется в верхний регистр.

## Клинические данные

Основной и сопутствующий диагнозы необязательны, но при заполнении выбираются
из активного локального каталога и хранятся раздельно как код, название и версия
классификации. В настройках приложения доступны МКБ-10 и МКБ-11; по умолчанию
используется МКБ-10, а выбор сохраняется в локальной БД между запусками.

Встроенные наборы сверены с WHO ICD-10 (`2019`) и WHO ICD-11 MMS (`2026-01`):
<https://icd.who.int/browse10/2019/en> и
<https://icd.who.int/browse/2026-01/mms/en>.

При включённой ИВЛ обязательны режим, FiO₂ (21–100 %) и ПДКВ (0–50 cmH₂O).
При выключенной ИВЛ связанные параметры очищаются. Каталог вынесен за Qt-слой,
поэтому его можно заменить полным лицензированным выпуском МКБ-11 без изменения
карточки пациента.

## Поиск и выбор

Поиск выполняется по частичному совпадению ФИО, ID или номера истории болезни,
ограничен 50 результатами и запускается с задержкой 150 мс после ввода. Выбор
подсказки загружает существующую карточку вместо создания новой.
