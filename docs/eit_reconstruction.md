# Реконструкция реальных измерений ЭИТ

## Статус и область применимости

В приложении реализован исследовательский вычислительный контур
`eit-greit-fem-research-1.0.0`:

`JSON 208 каналов → опорный вектор → ΔV → 2D FEM/CEM → GREIT → Δσ → ΔZ → показатели аэрации`.

Численный расчёт выполняется по реальным входным значениям и не использует
синтетическую карту симулятора. При этом встроенные порядок каналов
`adjacent-16x13-hypothesis-v1`, круглая геометрия и ориентация электродов не
подтверждены документацией конкретного прибора. Поэтому такие кадры получают
качество `degraded` и не должны интерпретироваться как клинически
валидированные изображения.

## Загрузка JSON

На экране «Пациент» доступна кнопка «Загрузить измерения ЭИТ из JSON».
Файл открывается в архивном режиме только для чтения. Доступны пауза,
перемотка и скорости 0,5×–4×.

Поддерживается наблюдаемый формат проектов ЭИТ:

- корневые ключи кадров — последовательные числа от `0` без пропусков;
- кадр — массив 208 чисел или объект `{"0": [208 чисел]}`;
- один пояс, 16 электродов, 208 каналов;
- необязательные `metadata`, `_metadata`, `protocol`, `param`;
- `param` вида `1_1_100_5.000000` используется для получения 100 кГц и 5 мА;
- при отсутствии FPS используется 25 кадров/с.

Исходный JSON не изменяется.

## Опорный вектор и качество каналов

Опора строится поканальной медианой первых
`max(3, round(FPS × 1 с))` кадров. Для seekable JSON эта опора вычисляется
заранее и сохраняется при перемотке; живой источник сначала накапливает её:

`V_ref[c] = median_t(V[t,c])`.

Если статический JSON содержит только один или два кадра, существующие кадры
повторяются до минимальных трёх образцов без изменения их значений. Это позволяет
открыть и циклически воспроизводить фантом, но не создаёт отсутствующий baseline:
для одного неизменного кадра `ΔV` и time-difference карта будут нулевыми.

Для каждого последующего кадра:

`ΔV[t,c] = V[t,c] - V_ref[c]`.

По опорному интервалу рассчитывается медианное абсолютное отклонение каждого
канала. Каналы с отклонением более восьми типичных медианных отклонений
исключаются нулевым весом. Реконструкция блокируется, если пригодно менее 104
из 208 каналов.

## Прямая модель

Используется двумерная линейная треугольная конечно-элементная модель и полная
электродная модель (Complete Electrode Model, CEM):

- круглый контур взрослого радиусом 0,15 м;
- 16 электродов на границе;
- сетка низкой плотности: 224 треугольных элемента;
- эффективный контактный импеданс 0,01 Ом·м;
- фоновая проводимость 1 См/м;
- ток берётся из JSON и переводится из мА в А.

Прямая задача решает дискретизированное уравнение
`∇·(σ∇u)=0` с CEM-граничными условиями. Якобиан
`J = ∂V/∂σ` вычисляется методом сопряжённых полей и имеет размер 208×224.

## Обратная задача GREIT

Линейный оператор GREIT обучается на локальных гауссовых изменениях
проводимости внутри FEM-контура. Используются:

- карта 64×64;
- относительная регуляризация Тихонова не менее `0,02`;
- целевой noise figure `0,5`;
- веса пригодности измерительных каналов;
- кэширование оператора для одинаковых протокола, геометрии, тока и весов.

Для каждого кадра выполняется:

`Δσ_pixels = R_GREIT · ΔV`.

Поскольку увеличение воздухонаполнения обычно увеличивает импеданс и снижает
проводимость, доменная карта аэрации задаётся как:

`ΔZ_like = -Δσ`.

Значения вне FEM-контура заменяются нулём. Каждый из 4096 элементов карты
отображается интерфейсом отдельно.

В составе расчётного ядра также присутствует итерационный Gauss–Newton с
регуляризацией Тихонова. Потоковое воспроизведение использует GREIT, поскольку
его оператор строится один раз, а новый кадр требует только матричного
умножения.

## Расчёт аэрации

Реконструированные кадры поступают в общий `AerationProcessor`. Внутри
фиксированных масок правого и левого лёгкого карта делится на восемь ROI.
Суммы элементов формируют глобальную и регионарные плетизмограммы, из которых
рассчитываются RR, TVi, EELI, EILI, R/L, V/D и доли ROI.

Короткая запись может быть пригодна для реконструкции карты, но недостаточна
для дыхательных параметров. Например, предоставленный `sample_sitting.json`
содержит только 98 кадров при 25 Гц (около 3,9 с), поэтому RR может оставаться
недоступной даже при реконструкции всех кадров относительно общей опоры.

## Необходимая валидация

До использования с целевым прибором необходимо заменить гипотезы подтверждённым
профилем:

1. таблицей 208 каналов «токовая пара → измерительная пара»;
2. единицами, знаком и масштабом напряжений;
3. нумерацией и анатомической ориентацией электродов;
4. геометрией грудной клетки и параметрами электродов;
5. фантомными измерениями с известными положением и проводимостью объектов;
6. утверждённым правилом опорного интервала и клинической проверкой показателей.

До этого абсолютные значения `Δσ`, ориентация R/L и медицинская интерпретация
карты являются исследовательскими.
