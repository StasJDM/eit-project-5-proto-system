## Ключевые решения

### Стек технологий

| Выбор | Обоснование |
|---|---|
| PySide6 | Нативный Qt, LGPL-лицензия, работает на Windows/macOS/Linux |
| numpy | Только для генерации мок-данных (синусоиды + шум) |
| Нет matplotlib / pyqtgraph | Кривые рисуются через QPainterPath — нет лишних зависимостей |

### Рендеринг кривых

Используется кастомный `_WaveCanvas(QWidget)` с `paintEvent` + `QPainterPath`.
Обновление: 10 кадров/с (QTimer 100 мс). Частота дискретизации симулятора — 25 Гц (таймер 40 мс).

### Структура навигации

Заголовок (`HeaderBar`) и панель навигации (`NavPanel`) — постоянные виджеты MainWindow.
Переключение экранов — `QStackedWidget`. Навигационная панель справа, как в макете.

### Список экранных форм

Список кнопок навигации формируется строго по п.6 ТЗ (10 форм).
Форма «PEEP», присутствующая в макете, в ТЗ отсутствует — **не включена**.
Форма «ОТЛАДКА И ТЕСТИРОВАНИЕ» в макете отсутствует, но в ТЗ есть — **включена**.

### Мок-данные

`BreathingSimulator` генерирует 9 каналов:
- Канал 0: глобальный LI (сумма) — `sin(2π·0.25·t)` + шум 2.5%
- Каналы 1-4: ROI правого лёгкого (амплитуды `[0.27, 0.24, 0.23, 0.21]`, малые фазовые сдвиги)
- Каналы 5-8: ROI левого лёгкого (амплитуды `[0.25, 0.22, 0.20, 0.19]`)

Параметры мок-данных:
- RR = 15 вд/мин (эупноэ)
- Правое лёгкое: 52% вентиляции
- Левое лёгкое: 48% вентиляции
- L/R ≈ 1.08, V/D ≈ 0.85

## Соответствие ТЗ

### п.5 — Отображаемая информация

| Требование ТЗ | Реализация |
|---|---|
| Кривые глобальной аэрации | WaveformPanel секция T (1 кривая) |
| Кривые регионарной аэрации | WaveformPanel секции R (ROI_1-4) и L (ROI_5-8) |
| Тренды глобальной аэрации | Экран ТРЕНДЫ (заглушка) |
| Тренды регионарной аэрации | Экран ТРЕНДЫ (заглушка) |
| Параметры неоднородности аэрации | N,% для каждого ROI |
| Параметры динамики аэрации | T,% / R,% / L,% / L/R / V/D в LeftPanel |
| Частота дыхания (RRi) | ЧД-дисплей в строке T |
| Счётчик длительности ЭС | Поле «Время использ. ЭС» |
| Текущая длительность мониторинга | Поле «Длительность ЭИТ» |
| Тип дыхания (текст) | HeaderBar — поле типа дыхания |
| Сведения о пациенте | Экран ПАЦИЕНТ (заглушка) |
| Текстовая сигнализация | HeaderBar — кнопка СИГНАЛ ТРЕВОГИ |
| Визуализация дыхательного цикла | LungVizWidget (торакс + лёгкие) |
| Световая сигнализация | HeaderBar — цветовая индикация тревоги |

### п.6 — Экранные формы

Все 10 форм зарегистрированы в `MainWindow`.

### п.7 — Многоязычность

**Не реализовано в прототипе.** Интерфейс — русский. Для добавления:
- Использовать `QTranslator` + `.ts`/`.qm` файлы
- Строки вынести в отдельный файл локализации

### п.8 — Протоколирование событий

**Не реализовано.** Предполагается в экране СЛУЖЕБНАЯ ИНФОРМАЦИЯ:
- Текстовые поля для ввода оператором
- Сохранение в JSON/SQLite лог-файл
